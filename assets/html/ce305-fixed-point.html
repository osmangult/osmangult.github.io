Fixed-point iteration

Rewrite f(x) = 0 as x = g(x). Feed each answer back into g. The path between the curve y = g(x) and the line y = x shows whether it closes in on the root or runs away.

How fast does the error drop?

εaεtdashed: stopping value

When it converges, the error shrinks by about the same factor |g′(xr)| every step: a straight line here, like bisection, but the slope depends on g.

Problem

Write x for the variable, * for multiplication, ^ for powers. Available: exp, ln, log10, sqrt, sin, cos, tan, arcsin, arccos, arctan, abs, pi.

The update rule

xi+1 = g(xi)

Near a root xr the error is multiplied by about g ′(xr) each step. So it converges when |g ′(xr)| < 1. The sign of g ′ decides staircase (+) or spiral (−).

εa = |xi+1 − xixi+1| × 100%
