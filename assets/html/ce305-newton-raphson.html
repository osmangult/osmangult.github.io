Newton–Raphson method

Start from one guess. Draw the tangent to the curve there and follow it down to the x-axis. Where it lands is the next guess.

How fast does the error drop?

εaεtdashed: stopping value

Once close to the root, each step roughly squares the error, so the points bend sharply downwards. That is quadratic convergence.

Write x for the variable, * for multiplication, ^ for powers. Available: exp, ln, log10, sqrt, sin, cos, tan, arcsin, arccos, arctan, abs, pi.

The update rule

xi+1 = xi − f(xi)f ′(xi)

Where the tangent at (xi, f(xi)) crosses y = 0. It is the first-order Taylor series set to zero.

εa = |xi+1 − xixi+1| × 100%
